Acerca

Ingeniería con propósito

Diseño y construyo agentes de IA que resuelven problemas reales. Mi stack combina modelos locales (Ollama) con proveedores cloud para optimizar costos — cada token cuenta. Implemento sistemas RAG extremo a extremo con control de alucinaciones, chunking semántico y recuperación híbrida.

Creo en la creatividad para tiempos cambiantes: elegir la herramienta correcta para el objetivo, no por moda. Mis sistemas priorizan fiabilidad, estabilidad y uso inteligente de datos. Cada solución pasa por testing riguroso de agentes y validación continua.
